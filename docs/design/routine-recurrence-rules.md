# 루틴 반복 날짜 규칙

이 PR은 루틴 날짜 계산의 경계를 먼저 구현한다. 루틴 관리 화면, 저장 테이블,
실제 일정·Todo 생성은 후속 PR에서 이 계산 결과를 사용한다.

- 시작일은 필수이며 종료일은 포함한다. 종료일이 없는 루틴은 수동 추가만 가능하다.
- 매일·매주·매월·매년과 사용자 정의 간격(일·주·월·년)을 지원한다.
- 주간 요일은 월요일부터 일요일까지 복수 선택할 수 있다. 선택하지 않으면 시작일의 요일을 사용한다.
- `2주마다`처럼 간격이 있는 주간 규칙은 시작일이 속한 주를 첫 주로 잡는다.
- 매월 31일은 31일이 없는 달의 마지막 날에, 2월 29일의 매년 반복은 평년 2월 28일에 표시한다. 이후 유효한 달·연도에서는 다시 원래 날짜를 사용한다.
- 계산은 요청한 날짜 범위 안에서만 수행한다. 일 단위 차이 계산은 UTC 달력 날짜를 사용하므로 현지 DST로 하루가 23·25시간이 되어도 날짜를 건너뛰지 않는다.
- 수동 루틴 결과는 실제 Task가 아닌 가상 후보(`requiresConfirmation`)다. 같은 날짜를 다시 조회해도 후보는 남으며, 확정된 날짜를 전달할 때만 결과에서 제외된다.
- 자동 루틴 결과도 계산만 하고 DB에 쓰지 않는다. 후속 저장 계층에서 중복 방지를 위한 확정 날짜를 전달할 수 있다.
