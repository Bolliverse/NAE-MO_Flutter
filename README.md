# NAE-MO Flutter

NAE-MO 앱 Flutter 프로젝트입니다.

- **환경**: Flutter 3.24.5 / Dart 3.5.4
- **플랫폼**: Android / iOS / Web
- **패키지 ID**: `com.example.nae_mo`

## 시작하기

```bash
# 패키지 설치
flutter pub get

# 코드 생성 (freezed, riverpod, retrofit 등)
dart run build_runner build --delete-conflicting-outputs

# 앱 실행
flutter run
```
